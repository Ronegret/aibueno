# AIbueno

Landing site for **AIbueno** — a boutique AI agency (Barcelona · remote global)
offering web & mobile development, AI agents and business automation.

🌐 **Live:** [aibueno.es](https://aibueno.es)

> ℹ️ This repo is a clean, self-contained rebuild of the landing page with
> **placeholder/demo data** (sample projects, demo contact details).

## 📄 Sections
Hero · Web & Apps · AI Services · Work (samples) · Methodology · Pricing · FAQ · Contact

## 🛠️ Tech
Vanilla **HTML · CSS · JavaScript** — no build step, fully responsive, dark theme.

## 🚀 Run locally
Open `index.html` in a browser, or serve it:
```bash
python -m http.server 8080
# http://localhost:8080
```
