## 🧭 Overview
Landing site for AIbueno — a boutique AI agency (Barcelona · remote global) offering web & mobile development, AI agents and business automation. Static export of the production site.

## ✨ Features
- Hero, services, work, methodology, pricing, FAQ & contact
- Responsive, modern dark theme
- AI agents, web & app development offering

## 🛠️ Built with
`Next.js (static export)` · `HTML/CSS/JS`

## 🚀 Run locally
```bash
# open index.html, or:
python -m http.server 8080
```
